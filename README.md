# Blog Application — React Frontend

Frontend application for a blog platform, built with React.

## Overview
This repository contains the client-side blog experience. The implemented pages, components, routing, and API interactions are defined by the source code.

## Related Project
- [Blog Application Spring Boot Backend](https://github.com/MahiTzy/blog-app-backend-springboot)

## Technology
- React
- JavaScript
- CSS
- Create React App toolchain

## Prerequisites
- Node.js (LTS recommended)
- npm
- Backend service and API configuration, if required by the application

## Getting Started
```bash
git clone https://github.com/MahiTzy/blog-app-frontend-react.git
cd blog-app-frontend-react
npm install
npm start
```
Open [http://localhost:3000](http://localhost:3000).

## Available Scripts
- `npm start` — run the development server.
- `npm test` — run tests.
- `npm run build` — create a production build.

## Configuration
Check the source for the API base URL and configure it for your local backend. Do not place secrets in browser-exposed environment variables.
